# MultiRoute-Monitor

中国大陆多路线交通时间看板。一个页面最多 6 条独立路线卡片，显示 ETA、TMC 路况分段和可选高德底图；不提供导航。

## 启动

Windows 10/11、macOS、Linux：需要 Python 3.10+，不需要 pip、npm、Node.js 或云服务。

\`\`\`powershell
python app.py
\`\`\`

浏览器访问 \`http://127.0.0.1:8876/\`。默认只监听本机，不对局域网或公网开放。端口 8876 与 SRM 的 8765 分离。按 Ctrl+C 停止。

首次显示 4 条明确标记的虚构示例路线。用户在浏览器中编辑/添加真实路线名称和起终点，并填写高德 GCJ-02 经纬度，最多 6 条。路线配置保存在浏览器 localStorage；服务端不保存地址或路线响应。获取高德坐标可使用[官方坐标拾取器](https://lbs.amap.com/tools/picker)；中国大陆需使用高德坐标（GCJ-02），经度在前、纬度在后。

## 真实高德模式

真实模式默认关闭。仅在**高德已书面确认允许本项目的个人使用场景**、并且已在控制台核对本人账号剩余免费配额后，才可点击页面右上方「高德授权设置」。

该表单要求输入高德工单编号、驾车规划和 JS 地图初始化剩余配额，并确认：
- 已收到高德明确书面许可；
- 已核对账户级免费剩余额度；
- 同一账号没有其他应用/Key 共用并消耗相同配额；
- 理解超出免费额度后，高德可能消耗流量包和账户余额。

程序会把填写的剩余额度留出一半作为安全余量，并设置本应用硬上限：驾车规划最多 1,000 次/日、30,000 次/月；地图初始化最多 30 次/日、900 次/月；地图代理最多 500 次/日、15,000 次/月。路线查询按条排队，至少间隔 2.1 秒；同一路线 5 分钟内不重复。真实自动刷新是独立勾选项，默认关闭；开启后按页面所选 5/10/15/30 分钟间隔逐条刷新。

**重要：这些是本应用的本地限制，不是高德账号级计费硬停止。** 如果同账号其他应用消耗配额、控制台配额变动或高德调整规则，仍可能产生费用。不能确认账号独占和剩余额度时，不要启用。高德个人免费许可还要求“个人研究学习目的”，个人非商业不自动等于所有日常用途都获许可。

## 本机密钥

已有密钥可由项目根目录运行 \`python setup_amap.py\` 录入：Web 服务 Key、Web 端 JS API Key、JS 安全密钥。输入不回显，保存在 \`local/amap_keys.json\`。用户已配置时无需重做。授权状态与用量计数保存在同一 \`local/\` 目录，整个目录已被 Git 忽略。

服务端自动实现同源安全代理，不需要安装 Nginx。JS 安全密钥只保存在本机后端；JS API Key 按官方要求在浏览器加载地图时可见。地图只在真实路线查询成功后，用户再次点击该路线的「查看高德地图」时初始化。

## 隐私与安全

- 默认模拟模式无外部请求，不调用高德或其他外部 API。
- 不把 Key、安全密钥、真实路线、家庭/办公地址提交到 GitHub 或聊天。
- 不保存高德返回的路线、交通数据或历史响应。
- 所有真实请求都需本地明确授权，预算先计数再请求；计数损坏或超限时拒绝。
- 「停用真实接口」会立即写入本地关闭标记并恢复模拟模式。
- 仅监听 127.0.0.1，不是公网服务。
