# MultiRoute-Monitor｜技术决策记录

## 2026-11-02
| ID | 决策 | 原因 / 边界 |
|---|---|---|
| D001 | 独立 GitHub 仓库 MultiRoute-Monitor，main + feature branch + Draft PR + CI | 不影响 AIWorkSpace 与其他仓库 |
| D002 | 首版拆为 M1-A 模拟看板、M1-B 真实高德数据 | 严格 0 元、不冒充真实路况、先证实 UI |
| D003 | 只用 Python 标准库 + 原生 HTML/CSS/JS | 本地运行、无包管理与付费服务 |
| D004 | 模拟曲线是纯示意绘图，非道路地理坐标 | 高德地图授权/Key 未验证，不提供虚假数据 |
| D005 | 高德方向为 Web 服务路径规划 2.0 + JS API 2.0（待合法授权后验证） | 规划接口含 time/distance/TMC 的可能性；不把文档当真实接口验收 |
| D006 | 浏览器 localStorage 存用户手动输入的路线配置，不存服务响应/路况历史 | 减少数据风险，符合首版范围；真实模式需再次审查协议 |
| D007 | 默认仅 127.0.0.1，允许本地 Host，无网络依赖 | 本地隔离、安全与离线模拟 |
| D008 | 不直接复制无明确 LICENSE 的 amap_commute；MIT 源码可在保留声明条件下复用 | GitHub 公共仓库不等于授权，M1-A 暂不需要第三方源码 |
| D009 | 真实模式前设置严格调用硬上限、账号侧确认费用/授权；不默认允许商用 | 免费额度、API 条款、用途需用户账号验证 |
| D010 | 固定路线与途经点的准确语义待 M1-B 实测 | 起终点规划可能每次变化，需与固定道路路线区分 |
