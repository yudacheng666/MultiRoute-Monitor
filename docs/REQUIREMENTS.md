# MultiRoute-Monitor｜需求基线 M0 / M1-A

状态：首版方向来源于用户 2026-11-02 的需求；详细真实服务授权尚未确认。本文件写明已确定的需求与当前阶段范围，尚未完成的能力不可标 PASS。

## 目标
中国大陆多个指定驾车路线在一个网页同时显示预计时间、交通状态和路线示意。无 GPS 跟踪、语音引导或导航操作。先 Windows 电脑本地运行、GitHub 管理、严格 0 元。

## M1-A（本 PR 要交付）
- 默认展示 4 条明确标记的虚构路线，响应式 2/3 列网格，最多 6 个小窗。
- 每个窗口独立展示虚构路线名称、起终点、模拟 ETA、模拟延误、模拟分段路况与最后模拟刷新时间。
- 显著、始终可见“模拟模式 / 非真实路况”标识；示意线不是地理坐标上的真实道路地图。
- 支持增添、修改、删除本地路线；刷新单条/全部；暂停/恢复自动刷新；选择 5/10/15/30 分钟。
- 用户自填路线名称和起终点须校验长度及防 HTML 注入；刷新或重开页面后路线和刷新选项仍保存在本机浏览器。
- API 禁止真实高德/外部请求；不需要 Key；仅在 127.0.0.1 服务。
- 错误与空态有明确反馈，不写入浏览器外的个人数据。

## M1-B（当前不交付）
- 高德 v5/direction/driving 的实时 ETA、distance、tmcs/路线分段坐标。
- 用高德 JS API 2.0 显示实际地图、路线标注和交通分段色。
- 地图 JS API / Web Service Key 与安全代理的合规配置。
- 实际免费配额及使用场景（个人/公司）授权核对；有效账号下有限调用的真实接口探针。
- 拥堵和路由真实刷新、故障策略、调用预算硬限制、实际路由固定途经点验收。

## 明确排除
收费资源、后台云服务、商用调度、持续定位、语音导航、历史路况持久保存或公开的交通数据转售/API。

## M1-A 验收
1. 浏览器同屏四条模拟路线，所有数据明显标记为模拟。
2. 新增/编辑/删除并刷新浏览器，配置不丢失；超过 6 条被阻止。
3. 手动单条/全部刷新正确更新；自动刷新/暂停切换按配置运行。
4. 用户输入的 HTML/脚本被作为文本显示，不执行。
5. 本机服务仅监听 127.0.0.1，非法 Host、未知路径及遍历访问被拒绝。
6. 无外部 JS/CDN/API/Key，模拟服务 status 明确返回 live_enabled=false。
7. Python + Node 单元/HTTP 集成 + 真浏览器定向 E2E 通过；Windows/Linux GitHub CI 按准确 SHA 验证。
8. 不自动合并 main、不在用户电脑部署。
